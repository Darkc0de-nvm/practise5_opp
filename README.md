# Патерн «Фабрика» (C#)

Завдання з реалізації різних видів фабрик у C#. Репозиторій містить п'ять консольних проєктів із прикладами роботи патернів та шосте завдання (.md) з вибором відповідного підходу.

## Структура

| Проєкт | Опис |
|---|---|
| `Task1_ColorFactoryMethods` | Створення кольорів через RGB, HSV та HEX за допомогою фабричних методів. |
| `Task2_SeparateFactory` | Порівняння окремої (`ColorFactory`) та внутрішньої (`Color.Factory`) фабрик. |
| `Task3_AsyncFactory` | Асинхронне завантаження курсів валют через `CreateAsync()`. |
| `Task4_AbstractFactory` | Створення елементів інтерфейсу для світлої, темної та висококонтрастної тем. |
| `Task5_RegistryFactory` | Фабрика з реєстрацією каналів Email, SMS і Telegram. |
| `Task6.md` | Вибір відповідного способу створення об'єктів для шести ситуацій. |

## Запуск

Для запуску потрібні: Visual Studio або .NET SDK (6.0+)

1. Відкрити рішення `Practise5` у Visual Studio.
2. Вибрати потрібний проєкт і запустити.

Запуск через термінал (приклад):

```bash
cd Task3_AsyncFactory
dotnet run
```

## Перевірка

Основні результати виконання:

- **Завдання 1:** RGB, HSV та HEX повертають однаковий колір `#FF8800`.
- **Завдання 2:** обидві фабрики створюють `#00FF00`; приватний конструктор варіанта Б недоступний ззовні.
- **Завдання 3:** конвертація 1000 грн у USD за заданим курсом повертає `25`.
- **Завдання 4:** кнопка та прапорець створюються відповідно до вибраної теми.
- **Завдання 5:** підтримується створення каналів за назвою, незалежно від регістру, та обробка помилок реєстрації.
